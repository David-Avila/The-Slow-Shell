# The Slow Shell (DSS)
DSS is a small custom shell for MiniMicro.

# NOTE:
This projects is **WIP**. Expect bugs

# How to install
Just copy and paste this line into MiniMicro's terminal

```
f=file.open("_temp.ms","w+");f.write(http.get("https://github.com/David-Avila/The-Slow-Shell/blob/main/installer.ms").utf8);f.close;load"_temp";run
```
